# Рабочие сценарии

Не «что агент теоретически может», а как им реально пользуются каждый день.

## Учёба

**Разбор непонятного.**
```
Прочитай study/lecture-4.md. Объясни раздел «X» простыми словами, как первокурснице. Где в тексте пропущен шаг — скажи об этом прямо, не заполняй пробел догадкой.
```

**Проверка себя.** Сначала решаешь сама, потом:
```
Вот моё решение: [решение]. Найди ошибку, но не решай за меня — скажи, на каком шаге я свернула не туда.
```

**Конспект.**
```
Сожми study/lecture-4.md до одной страницы: определения, формулы, 3 главные идеи. Ничего не добавляй от себя.
```

Важно: агент нужен, чтобы **понять**, а не чтобы сдать за тебя. Сданное непонятое возвращается на экзамене.

## Работа

**Черновик.** Письмо, план, описание — пусть напишет первую версию, ты доводишь. Смотреть на готовый черновик легче, чем на пустой лист.

**Второе мнение.**
```
Прочитай work/plan.md и назови 3 слабых места. Коротко.
```

**Рутина.** Всё, что делаешь одинаково каждую неделю — опиши один раз в файле и запускай ссылкой на него. Это и есть настоящая экономия времени.

## Про ИИ (папка `ai/`)

Заведи привычку: прочитала статью или посмотрела видео — попроси
```
Сделай в ai/ заметку по этой статье: 3 идеи, 1 вопрос, который остался.
```
Через месяц у тебя не «я что-то читала», а база, к которой агент может обращаться.

## Хороший ритм дня

1. Начала задачу → новый чат.
2. Сначала попросила план, поправила.
3. Работаешь маленькими шагами, проверяешь каждый.
4. Он ошибся, ты объяснила → правило поехало в `AGENTS.md`.
5. Закончила → результат лежит файлом, а не в чате.

## Одна мысль напоследок

Люди застревают на «умею писать запросы». Разница между новичком и опытным — не в запросах, а в том, что у опытного **накоплен контекст**: файлы, правила, заметки. Агент у него сильнее не потому, что модель другая, а потому что она наконец знает, с кем работает.
