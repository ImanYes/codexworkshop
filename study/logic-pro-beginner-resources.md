# Logic Pro: подборка для новичка

Собрано: сентябрь 2026. Версия 2 — расширенная и уточнённая.

**Как проверялось.** Каждый пункт найден через веб-поиск и подтверждён минимум одним источником (ссылки в тексте). Сами страницы открыть не удалось — сеть окружения их блокирует. Поэтому перед установкой смотри официальный сайт: цены и условия меняются.

> **Главное правило:** Logic Pro работает только с плагинами формата **AU** (Audio Unit — формат плагинов Apple). VST/VST3 не загрузятся. Скачивая плагин, выбирай версию «AU» / «macOS».

---

## 0. План старта

1. **Неделя 1–2:** один курс по интерфейсу (раздел 2) + встроенные звуки Logic (раздел 3).
2. **Параллельно:** теория музыки 15–20 минут в день (раздел 6).
3. **Неделя 3+:** первые бесплатные плагины (раздел 4) и сэмплы (раздел 5).
4. **Всегда:** вопросы — в сообщества (раздел 7).

Не качай 50 плагинов сразу. Встроенных инструментов Logic хватит на первые месяцы.

## 3. Что уже есть внутри Logic (начать отсюда)

- **Sound Library** — бесплатные паки звуков от Apple, royalty-free (можно использовать в своих треках без отчислений). Открывается: *Logic Pro → Sound Library*. Полная библиотека ~80 ГБ — ставь паки по мере нужды.
- **Session Players** (Logic 11+) — виртуальные барабанщик, басист и клавишник. Ставишь — они сами играют партию, ты выбираешь стиль. Для новичка идеально. [Гайд Apple](https://support.apple.com/guide/logicpro/session-players-overview-lgcpbf624405/mac)
- **Stem Splitter** (11.2) — делит готовую песню на 6 дорожек: вокал, барабаны, бас, гитара, пианино, остальное. Удобно учиться, разбирая чужие треки ([MusicTech](https://musictech.com/news/gear/apple-logic-pro-11-2-ipad-2-2-stem-splitter-flashback-capture-price-everything-else-you-need-to-know/)).
- **Flashback Capture** (Shift+R) — если сыграл хорошо, но забыл нажать запись, Logic всё равно сохранит сыгранное.
- **Встроенные эффекты** (EQ — эквалайзер, компрессор, ревербератор) — одни из лучших стоковых среди DAW (DAW — программа для создания музыки). Учись сначала на них.

Что нового в 11.2 — [Apple](https://support.apple.com/guide/logicpro/whats-new-in-logic-pro-112-lgcp02e40443/mac), [Logic Pro Help](https://www.logicprohelp.com/articles/logic-pro-112-new-features-explained-r26/).

## 5. Библиотеки звуков

Сэмпл — короткий записанный звук (удар барабана, нота). Луп — зацикленный фрагмент (например, 4 такта ритма).

| Где | Что | Бесплатно? |
|---|---|---|
| [Pianobook](https://www.pianobook.co.uk/) | 1200+ инструментов от сообщества; есть формат для Decent Sampler и сэмплера Logic | да ([MusicRadar](https://www.musicradar.com/news/fantastic-free-plugins-pianobook-decent-sampler)) |
| [99Sounds](https://99sounds.org/sounds/) | сэмплы, лупы, звуковые эффекты; 100% royalty-free, в т.ч. для коммерции | да |
| [Looperman](https://www.looperman.com/) | лупы от пользователей по жанрам | да, но качество разное |
| [Cymatics](https://cymatics.fm/pages/free-sample-packs-license-agreement) | бесплатные паки: барабаны, мелодии, вокал | да, при регистрации; читай лицензию |
| [Splice](https://splice.com/) | огромная библиотека | нет, подписка — не на старте |

### На английском
- [r/LogicPro](https://www.reddit.com/r/LogicPro/) — раздел на Reddit о Logic; самое активное англоязычное сообщество.
- [Logic Pro Help Forum](https://www.logicprohelp.com/forums/) — старейший форум (не путать с русской школой). Баги, обходные решения, новости обновлений.
- [Apple Community — Logic Pro](https://discussions.apple.com/community/applications-services/logic-pro) — официальный форум поддержки.
- Discord: сервер Logic Pro X & GarageBand ([top.gg](https://top.gg/servers/406099316499808256), ~1500 участников); [LogicBand](https://logic.band/join-logicband-on-discord/) — сообщество незрячих музыкантов, но открыто для всех. ### Известные баги
- Logic + звонок в Discord одновременно может «вешать» звук и мышь ([тред Apple](https://discussions.apple.com/thread/253581399)).
- Плагины Spitfire/LABS иногда не видны в Logic — решение в [теме форума](https://www.logicprohelp.com/forums/topic/156191-the-new-spitfire-audio-labs-plugin-issue/) и [справке Spitfire](https://support.spitfireaudio.com/en/articles/11816150-where-do-i-install-my-plugins-for-logic-or-garageband).
