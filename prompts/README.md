# Шаблоны запросов

Копируй, подставляй своё вместо `[...]`. Со временем перепиши под себя — это черновики, а не святое писание.

## Разобраться

```
Прочитай [файл]. Объясни [тему] простыми словами, за 5-7 предложений. Я новичок — термины расшифровывай. Чего в тексте нет — не придумывай, так и скажи.
```

## Сначала план

```
Задача: [задача]. Пока ничего не делай. Опиши план в 5 пунктах и скажи, каких данных тебе не хватает.
```

## Конспект

```
Сожми [файл] до одной страницы: главные идеи, определения, что нужно запомнить. Только то, что есть в тексте.
```

## Вопросы для самопроверки

```
По [файл] составь 10 вопросов для проверки себя: 5 на определения, 5 на применение. Ответы отдельным блоком в конце.
```

## Проверь моё решение

```
Вот моё решение: [текст]. Найди ошибку и скажи, на каком шаге я свернула не туда. Не решай за меня.
```

## Черновик текста

```
Напиши [письмо/пост/план] на тему [тема]. Тон [деловой/дружелюбный], объём до [N] предложений. Сохрани в [папка/файл.md].
```

## Критика

```
Прочитай [файл]. Назови 3 слабых места и что с каждым сделать. Коротко, без вступления.
```

## Точечная правка

```
В [файл] измени только [что]. Остальное не трогай. После — покажи, что именно поменял.
```

## Честность

```
Отметь отдельно, в чём ты уверен, а что — предположение. Если не знаешь — скажи «не знаю».
```

## Заметка по прочитанному

```
Сделай в ai/ заметку по этому материалу: 3 идеи, чем полезно мне, 1 оставшийся вопрос. Файл назови по теме.
```
