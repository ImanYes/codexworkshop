# Воркшоп: как работать с агентами (Codex)

Это учебная база. Скачиваешь, ставишь Codex, открываешь эту папку в терминале — и дальше агент работает **внутри неё**: читает файлы, пишет файлы, помнит правила из `AGENTS.md`.

## С чего начать (30 минут)

1. `setup/01-install.md` — поставить Codex.
2. `setup/02-first-run.md` — первый запуск, что происходит на экране.
3. `concepts/01-what-is-agent.md` — что вообще делает агент и чем он не является.
4. `setup/03-first-task.md` — первая настоящая задача своими руками.

Дальше читай `concepts/` по порядку. Каждый файл — одна идея, 5 минут.

## Что где лежит

| Папка | Зачем |
|---|---|
| `setup/` | установка и первые шаги |
| `concepts/` | как агенты устроены и как ими пользоваться |
| `prompts/` | готовые шаблоны запросов, копируй и меняй под себя |
| `study/` | твоя учёба — конспекты, задачи, вопросы |
| `ai/` | всё про ИИ: что читаешь, что пробуешь, что не понял |
| `work/` | рабочие задачи и материалы |

Три последние папки пустые специально. Это твоё место — агент будет складывать туда результаты.

## Одно правило, если запомнить только одно

Агент не читает мысли и не видит твой экран. Он видит только то, что ты написал, и файлы в этой папке. Плохой результат почти всегда = мало контекста, а не «тупая модель».
