# Мехмат: первый курс — карта проекта

Визуальная новелла на Ren'Py. Все материалы игры — здесь, в одной ветке.

## Как забрать на компьютер

Первый раз (в Терминале, в папке, где хочешь хранить проект):

```bash
git clone https://github.com/ImanYes/codexworkshop.git
cd codexworkshop
git checkout claude/quirky-knuth-fmz9wh
```

Если папка `codexworkshop` уже есть:

```bash
cd codexworkshop
git fetch origin
git checkout claude/quirky-knuth-fmz9wh
git pull
```

Поиграть без git: двойной клик по `game/mechmath.command` (Mac). Он сам скачает Ren'Py и свежую версию игры из этой ветки.

## Проверка файлов (3 октября 2026)

Что было:
- Игра лежала в 4 ветках. `mechmath.command` (запуск) был в одной, сама игра — в другой. Теперь всё в `claude/quirky-knuth-fmz9wh`.
- Туда же слиты другие ветки: чай, Logic Pro, маршрут ДСК → МГУ (`study/`). К игре они не относятся.

Что не сходится между файлами:
1. **Одногруппники в прототипе были выдуманные** (Айгерим, Даурен, Мира…), а в досье — 26 настоящих псевдонимов. Исправлено: в прототипе теперь 6 человек из досье (см. `design/dialogues.md`).
2. **Знакомство:** в `study-day.md` старт отношений 5 + репутация ÷ 10, в коде — 20 + репутация ÷ 10 (так решил баланс, вопрос 5 в `balance.md`).
3. **Разговоры:** в `study-day.md` — «бросок кубика, каждый третий раз выбор реплики». Заменено новой системой из `design/dialogues.md`.
4. **`mehmat-design.md`, раздел 9:** «пока под номерами» — уже нет, псевдонимы есть. Раздел 18: часть вопросов решена в других файлах (времена года — `todo.md`, сцены отношений — `relationships.md`, мат — `students.md`).
5. **`mehmat-design.md`, раздел 17:** предложенных файлов (`rules.md`, `plot-act-1.md`, `events.md`, `endings.md`) нет. Сейчас то же самое разложено по другим файлам (таблица выше).
6. **`students.md`, Адалина:** в одном месте «линия — только дружба», в другом «любовь с героем: да», в «Решено» — «любовь только с героиней». Нужно одно решение.
7. **Две копии данных об одногруппниках:** `students.md` и `odnogruppniki.xlsx`. Надо выбрать одну главной, иначе они разъедутся.
