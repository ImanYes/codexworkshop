# 1. Установка Codex

Codex — это программа, которая запускается в **терминале**. Терминал — чёрное окно, куда пишут команды текстом. На Mac он называется «Терминал» (Terminal), найти через поиск (Cmd+Пробел → «терминал»). На Windows — «PowerShell».

## Шаг 1. Установить

Скопируй строку, вставь в терминал, нажми Enter.

**Mac / Linux:**
```
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

**Windows (PowerShell):**
```
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

Если у тебя уже стоит Node.js, можно и так:
```
npm install -g @openai/codex
```

Установка занимает минуту. В конце терминал напишет что-то вроде «installed».

## Шаг 2. Проверить

```
codex --version
```

Вышел номер версии — всё хорошо. Написал `command not found` — закрой терминал полностью, открой заново и повтори.

## Шаг 3. Войти

```
codex
```

Откроется меню — выбери **Sign in with ChatGPT**, откроется браузер, войди в свой аккаунт. Нужна подписка ChatGPT (Plus и выше) — на бесплатном аккаунте Codex не работает.

Вход делается один раз, дальше он тебя помнит.

Нажми на GitHub зелёную кнопку **Code → Download ZIP**, распакуй, положи куда удобно (например в «Документы»).
