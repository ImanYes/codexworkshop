# Отношения: сколько сцен и какие ивенты

Решено с автором.

## Общаться можно со всеми

С любым одногруппником можно говорить в универе. «Особенных» людей — несколько. У них есть свои сцены вне универа.

| Отношения | Сцены вне универа |
|---|---|
| Любовная линия | **2 сцены** + уникальный ивент, построенный на этом человеке |
| Только дружба | **1 сцена** |
| Нет линии | сцен нет, только общение в универе |

Пример — Вика:
- дружба → одна сцена: просто гулянка;
- любовь → две сцены, одна из них уникальная: например, она показывает свой аккаунт с танцами.

## Какие ивенты выпадают

- **По статам.** От статов зависит, какой ивент выпадет.
- **Уникальные.** У каждого, с кем возможна любовь, — свой ивент, построенный на его характере и хобби.
- **Низкая харизма** → маленькие ивенты. Пример: Саид помогает с ангемом — ночью вы остаётесь и разбираете задачи, он объясняет.
