# Logic Pro: подборка для новичка

Собрано: сентябрь 2026. Всё ниже — бесплатно, если не сказано иное.

> Важно: Logic Pro работает только с плагинами формата **AU** (Audio Unit — формат плагинов Apple). VST/VST3 не загрузятся. Перед скачиванием проверяй, что есть версия AU (для macOS).

## 0. Порядок старта

1. Разобраться с интерфейсом по одному видеокурсу (раздел 1).
2. Скачать встроенную библиотеку звуков Logic (раздел 2) — сторонние плагины пока не нужны.
3. Параллельно — основы теории (раздел 5), 15–20 минут в день.
4. Только потом добавлять бесплатные плагины (раздел 3).

## 2. Что уже есть внутри Logic (начать отсюда)

- **Sound Library** — бесплатные паки звуков от Apple, royalty-free (можно использовать в своих треках без отчислений). Скачиваются внутри Logic: меню *Logic Pro → Sound Library*.
- **Session Players** (Logic 11+) — виртуальные барабанщик, басист и клавишник. Ставишь — они сами играют партию, ты меняешь стиль. Для новичка идеально: быстро получается «живая» музыка. [Гайд Apple](https://support.apple.com/guide/logicpro/session-players-overview-lgcpbf624405/mac)
- **Встроенные эффекты** (EQ — эквалайзер, компрессор, ревербератор) — одни из лучших стоковых среди DAW (DAW — программа для создания музыки). Сначала учись на них.

| Плагин | Что это | Зачем |

Подборки для углубления: [BPB — 5 плагинов для новичков 2026](https://bedroomproducersblog.com/2026/05/05/5-free-plugins-for-beginners/), [Audeobox — бесплатные AU для Logic](https://www.audeobox.com/learn/logic-pro/best-free-au-plugins-for-logic-pro/).

## 4. Библиотеки звуков (сэмплы и лупы)

Сэмпл — короткий записанный звук (удар барабана, нота). Луп — зацикленный фрагмент (например, 4 такта ритма).

- [Pianobook](https://www.pianobook.co.uk/) — 1200+ бесплатных инструментов от сообщества, есть формат для Logic Sampler и Decent Sampler.
- [Looperman](https://www.looperman.com/) — бесплатные лупы от пользователей, по жанрам.
- [Cymatics — бесплатные паки](https://cymatics.fm/pages/free-sample-packs-license-agreement) — барабаны, мелодии, вокал (читай лицензию).
- [Splice](https://splice.com/) — огромная библиотека, **платная подписка**; стоит позже, не на старте.

## 5. Теория музыки (бесплатно, интерактивно)

- [Ableton Learning Music](https://learningmusic.ableton.com/) — ритм, мелодия, аккорды, бас прямо в браузере. Лучший старт для продюсера, подходит и под Logic.
- [musictheory.net](https://www.musictheory.net/) — уроки + упражнения и тренировка слуха.
