# 2. Первый запуск

## Главное правило: сначала зайти в папку

Codex работает **только с той папкой, из которой ты его запустила**. Файлы вне её он не видит. Поэтому сначала переходим в папку воркшопа.

В терминале:
```
cd путь/до/codex-workshop
```

Ленивый способ на Mac: напиши `cd ` (с пробелом в конце) и **перетащи папку мышкой прямо в окно терминала** — путь подставится сам. Enter.

Проверить, что ты там:
```
ls
```
Должен показать `README.md`, `concepts`, `study`, `ai`, `work`.

## Запуск

```
codex
```

Открывается окно чата прямо в терминале. Внизу строка ввода. Пиши задачу обычным текстом по-русски и жми Enter.

## Что происходит на экране

Codex не отвечает сразу текстом, как ChatGPT. Он **работает шагами** и показывает их:

- `Reading README.md` — читает файл
- `Running ls` — выполняет команду
- `Editing study/notes.md` — правит файл
- и в конце — короткий отчёт, что сделал

Ты видишь каждый шаг. Это нормально, что их много.

## Разрешения

Прежде чем что-то поменять или выполнить команду, Codex спрашивает разрешения. Варианты ответа:

- **Yes** — разрешить один раз
- **No** — не надо
- **Always** — больше не спрашивать про такое

Настроить, насколько часто он спрашивает: команда `/permissions` внутри чата.

Пока учишься — оставь режим, где он спрашивает. Так ты видишь, что он делает, и успеваешь остановить.

## Полезные команды внутри чата

| Команда | Что делает |
|---|---|
| `/init` | создать `AGENTS.md` — файл с правилами для агента |
| `/permissions` | что агенту разрешено |
| `/model` | выбрать модель |
| `/status` | показать текущие настройки |
| `/review` | проверить сделанные изменения |

Выйти — `Ctrl+C` два раза или команда `/quit`.
Вернуться к прошлому разговору — `codex resume`.
